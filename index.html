    如何启动与使用

    1. 在项目根目录执行 npm start（等同 node server.mjs），然后用浏览器打开终端里打印的地址，默认 http://127.0.0.1:4173/。
    2. 选择或拖动阵列布局，设定声源与云台位置，按「分析当前窗口」。
    3. 结果区给出首选来向、其他候选、可信范围与拟合残差；证据不足时会明确显示「证据不足」及原因，且不会给出可信方向。
    4. 「互相关峰」显示所选通道对的 GCC-PHAT 曲线、实测峰与几何允许的时差带；「方向与几何约束」显示候选扇形（俯视 + 侧视）。
    5. 「跟拍：开」后，跟踪器根据每帧结果决定转向或暂缓；平面阵出现镜像时先保持上次可信方向，用「探针转头」改变阵列姿态后可排除一支。
    6. 「方向跳变诊断」以来向跟踪的暂缓归属为参照，监测声源稳定但估计方向突跳的情况：通道互换、话筒掉线、符号错误、强反射、多峰歧义各有独立原因与阶段定位；「注入通道互换 / 注入话筒掉线」可现场制造故障观察诊断。每个事件可「定位到窗口」「回放该段」（原始多通道片段混音）与「复跑核验」（据记录证据重解算验证结论）。
    7. 「通道试听」可单独播放各声道；「打乱录制通道」用于验证通道顺序确实被显式处理。

    推断只接收 channels、sampleRate、通道映射、话筒位置与声速；页面上的仿真真值仅用于视觉校验，从不传入分析内核。
